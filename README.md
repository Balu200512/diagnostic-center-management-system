# Diagnostic Center Management System

## 1. Project Overview

The Diagnostic Center Management System is a web-based frontend project designed to provide a simple and user-friendly interface for diagnostic centers.

The system presents diagnostic test information and provides interfaces for patient registration and appointment requests. It aims to make it easier for users to navigate available services and submit basic details through a responsive web interface.

The project is developed using HTML5 and CSS3, focusing on page structure, visual design, responsiveness, and user experience.

## 2. Objectives

- Design a clean and responsive diagnostic center website.
- Provide a patient registration interface.
- Create an appointment request form.
- Display information about common diagnostic tests.
- Improve navigation and user experience.
- Demonstrate frontend web development skills.

## 3. Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of web pages and forms |
| CSS3 | Styling, layouts, colors, and responsive design |

## 4. Main Features

### Patient Registration
Provides a form interface for entering basic patient details, such as name and phone number.

### Appointment Request
Allows users to select a diagnostic test and enter a preferred appointment date.

### Diagnostic Test Information
Displays information about common tests, such as:
- Complete Blood Count (CBC)
- Blood Glucose Test
- Thyroid Profile

### Responsive User Interface
Uses CSS layouts and media queries to support different screen sizes, including desktop and mobile devices.

### Navigation
Provides navigation links to diagnostic services, appointments, and patient registration.

## 5. System Modules

**1. Home Page**

Introduces the diagnostic center and provides access to the main sections.

**2. Patient Registration Module**

Displays a form for entering basic patient information.

**3. Appointment Module**

Provides fields to select a test and preferred appointment date.

**4. Diagnostic Test Information Module**

Displays details about selected diagnostic services.

## 6. Project Workflow

1. The user opens the website in a browser.
2. The home page displays the available sections.
3. The user views diagnostic test information.
4. The user enters details in the registration or appointment form.
5. The frontend displays a demonstration message after form submission.

**Note:** This version is a frontend demonstration. It does not store patient information or create real appointments.

## 8. Installation and Setup

No additional software packages are required.

**Requirements:**
- A modern web browser
- A code editor such as Visual Studio Code

## 9. How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Balu200512/diagnostic-center-management-system.git
```

2. Open the project folder:

```bash
cd diagnostic-center-management-system
```

3. Open `index.html` in your browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension.

## 12. Limitations

- No backend server or database is connected.
- Patient details are not permanently stored.
- Appointment requests are demonstrations only.
- Authentication and administrative features are not implemented.
- The project is not intended for processing real patient information.
